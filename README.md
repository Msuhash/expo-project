# Expo Management Workspace

An online collaborative workspace for teams organizing indoor expos.

## Project Structure

- `backend/`: NestJS backend API with Prisma ORM and PostgreSQL.
- `frontend/`: Next.js web application.
- `EXPO_WORKSPACE_PROJECT_BRIEF.md`: Project brief and domain specification.

## Getting Started

### Backend
```bash
cd backend
npm install
npm run start:dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
